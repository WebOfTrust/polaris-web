# polaris-web

## Getting started

See [web-react](./examples/web-react/src/App.tsx) for an example react web app that uses this library to communicate with a signify browser extension.

To test the example, run the following commands from the project root directory:

1. Install dependencies: `npm install`
2. Build the library: `npm run build`
3. Start the example: `npm -w web-react start`

To view generated documentation, run the following commands from the project root directory:

1. `npm install`
2. `npm run build`
3. `npm run docs:serve`

## Usage

To use this library in your own project, install the package from GitHub. Run this command from your project directory:

```
npm install --save github:weboftrust/polaris-web#main
```

Change repository owner and branch as needed.
